# CI/CD Pipeline Project: Jenkins + GitHub + Maven + SonarQube

## Project Overview

This is a complete CI/CD pipeline project that demonstrates automated code quality analysis and continuous integration using Jenkins, SonarQube, and Maven.

## What This Project Does

- Automatically checks out code from GitHub
- Compiles Java project using Maven
- Runs static code analysis with SonarQube
- Displays code quality metrics in SonarQube dashboard
- All components run in Docker containers

## Tools Used

- Jenkins
- GitHub
- Maven
- SonarQube
- Docker

## Key learning points

- Jenkins pipeline scripting
- Docker networking
- Maven build lifecycle
- SonarQube integration
- Jenkins credentials and secret management
- systematic debugging
- tool version compatibility
- secure debugging using hashing
